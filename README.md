# Sprout Up! website

Public pages for **Sprout Up!**, a Sproutine game, served by GitHub Pages.

| Page | Link | Used for |
|---|---|---|
| 🔒 **Privacy policy** | [hmnafidr.github.io/sproutup-website/privacy.html](https://hmnafidr.github.io/sproutup-website/privacy.html) | Privacy policy URL in Google Play Console and App Store Connect |
| 💬 **Support** | [hmnafidr.github.io/sproutup-website](https://hmnafidr.github.io/sproutup-website/) | Support / website URL in the store listings |

## Files
- `privacy.html`: privacy policy for the web, Android and iOS versions
- `index.html`: support and contact page

Update `privacy.html` (and its effective date) **before** releasing any change in how the game handles
data, such as adding ads.
