# Sprout Up! website

Public pages for Sprout Up!, a Sproutine game, served by GitHub Pages:

- `index.html`: support and contact page (Support URL for Google Play and the App Store)
- `privacy.html`: privacy policy for the web, Android and iOS versions

Live at https://hmnafidr.github.io/sproutup-website/

Update `privacy.html` (and its effective date) **before** releasing any change in how the game handles data, such as adding ads.
